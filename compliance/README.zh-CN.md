# 企业验证与税务准备范围

[English](README.md) · [한국어](README.ko.md) · [简体中文](README.zh-CN.md)

Core 优先实现隐私结算。初期准备面向美国与阿联酋阿布扎比。每个企业/付款必须确定美国州/联邦范围，以及 ADGM 或阿布扎比大陆身份；这些司法辖区不可混用。[服务概览](../docs/SERVICE.md) · [路线图](../docs/ROADMAP.md)。

## 已实现

Front `/kyb/` 分为概览、企业、人员/受益所有权、文件、审核与状态六页，属于**示例资料流程**。草稿仅在内存中，刷新或离开 KYB 布局即清除，不读取或上传文件内容。完成字段及权限确认后可下载本地准备文件；编辑会使准备失效，变更辖区会清除依赖信息。

导出明确标记 `verified: false`、`credentialIssued: false`、`providerSubmission: not_sent`。没有服务商接收请求、企业获批或支付资格签发。

独立 KYB SDK 验证明确受信签发者的 Ed25519 签名、主体绑定、到期及提供的撤销信息。这些密码学检查不执行身份审查、自动获取最新服务商决定，也不在当前电路中强制准入。

收据提交声明字段并支持选择性完整性证明。独立证据验证可将选定交易记录锚定至最终事件，但不证明声明真实、法律身份、完整企业历史、税务认证或申报获受理。发票支付要求已签名单位引用，不能以任意收据根替换。

## 计划中的准备流程

1. 区分 B2B、员工或承包商付款，确定双方相关辖区及生效日期。
2. 明确美国州/联邦义务或 ADGM/大陆身份，再选择带日期及版本的官方规则。
3. 使用经审核的确定性规则计算，AI 负责生成附来源、可复核的解释与文档草稿。
4. 接入真实 KYB/KYC 服务商进行企业/受益所有人审核、可信凭证及最新撤销处理。电路强制资格需要单独版本的合约/电路。
5. 支持文件在链下加密，设置访问控制及保留/删除规则，向授权审核人选择性披露。
6. 经过相应审核后进入另行实现的申报/缴付流程；准备不等于批准或提交。

税率/税额计算、工资预扣、税收协定分析、AI 法律草稿、真实服务商调用、法定申报及法币兑换**尚未实现**。当前界面不推断税率或法律结论。

不要将法定姓名、受益所有权文件、薪资明细或原始税表放在链上。[隐私](../docs/PRIVACY.md) · [浏览器收据](../docs/BROWSER_RECEIPTS.md) · [发票](../docs/INVOICES.md)。
