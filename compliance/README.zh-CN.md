# 后续合规范围

[English](README.md) · [한국어](README.ko.md) · [简体中文](README.zh-CN.md)

初始司法辖区为美国（联邦层面，州尚未确定）和阿拉伯联合酋长国阿布扎比（尚未确定采用 ADGM 还是本土司法辖区）。

优先实现隐私结算。本核心**尚未实现**税率计算、AI 法律材料准备、工资扣缴、税收协定分析、真实 KYB 服务商调用或法定申报。

后续流程：选择 B2B / 员工 / 独立承包商 → 确定司法辖区及适用日期的官方规则 → 使用确定性规则计算 → 准备附有来源引用的 AI 草稿 → 将加密文档包及其 commitment 附加到收据。不得将真实姓名、受益所有人文件、工资或原始税务文件放到链上。

KYB SDK 验证明确信任的发行方签名、主体绑定、有效期和提供的撤销列表。它本身不确立身份，也不是由电路强制执行的准入策略。隐私资格凭证电路可作为单独版本的池加入。
