# 기업 검증과 세무 준비 범위

[English](README.md) · [한국어](README.ko.md) · [简体中文](README.zh-CN.md)

Core는 프라이버시 정산부터 구현합니다. 초기 준비 대상은 미국과 UAE 아부다비이며 각 기업·결제의 미국 주/연방 범위, ADGM 또는 아부다비 본토 구분을 확정해야 합니다. 서로 대체 가능한 관할이 아닙니다. [서비스 개요](../docs/SERVICE.md) · [로드맵](../docs/ROADMAP.md).

## 구현된 기능

Front `/kyb/`는 개요·기업·관계자/실소유자·문서·검토·상태의 6단계 **샘플 입력**입니다. 초안은 메모리에 있고 새로고침·KYB 이탈 시 삭제합니다. 파일 내용은 읽거나 업로드하지 않습니다. 입력과 권한 확인을 마치면 로컬 준비 파일을 다운로드할 수 있으며 수정은 준비 결과를 무효화하고 관할 변경은 관련 정보를 지웁니다.

내보낸 결과는 `verified: false`, `credentialIssued: false`, `providerSubmission: not_sent`입니다. 제공자 전송·법인 승인·결제 자격 발급은 없습니다.

별도 KYB SDK는 명시적으로 신뢰한 발급자의 Ed25519 서명, 대상 바인딩, 만료와 제공된 취소 목록을 확인합니다. 이 암호 검사는 실제 신원 심사·최신 제공자 결정 자동 조회·현재 회로의 강제 접근 정책이 아닙니다.

영수증은 선언된 필드의 커밋먼트와 선택적 무결성 증명을 지원합니다. 별도 증빙 검증으로 선택한 거래 기록을 최종 이벤트에 연결할 수 있지만 진실성·법적 신원·전체 기업 이력·세무 증명·신고 수리를 보장하지 않습니다. 인보이스는 서명된 단위 참조가 필요하며 임의 영수증 루트로 교체할 수 없습니다.

## 예정된 준비 과정

1. B2B·근로자·계약자 지급을 분류하고 당사자의 관련 관할과 적용일을 확정합니다.
2. 미국 주/연방 의무 또는 ADGM/본토 지위를 정한 후 날짜·버전이 있는 공식 규칙을 선택합니다.
3. 검토된 결정적 규칙으로 계산하고 AI는 출처가 있는 검토 가능한 설명·문서 초안을 준비합니다.
4. 실제 KYB/KYC 제공자를 연동해 법인·실소유자 심사, 신뢰 자격과 최신 취소 상태를 처리합니다. 회로 강제 자격에는 별도 버전의 컨트랙트·회로가 필요합니다.
5. 증빙 문서를 접근 제어·보관/삭제 정책과 함께 오프체인 암호화하고 권한 있는 검토자에게 선택 공개합니다.
6. 적절한 검토와 별도 구현된 신고·납부 과정으로 연결합니다. 준비는 승인·제출이 아닙니다.

전체 세액·급여 원천징수, 조세 조약 분석, AI 법무 초안, 법정 신고·법정화폐 환전은 **미구현**입니다. 현재 UI로 세율·법적 결론을 추정하지 않습니다.

법적 이름·실소유자 문서·급여 상세·원본 세무 서식을 온체인에 올리지 않습니다. [프라이버시](../docs/PRIVACY.md) · [브라우저 영수증](../docs/BROWSER_RECEIPTS.md) · [인보이스](../docs/INVOICES.md).

별도의 [Sumsub 연동](../docs/VERIFICATION.md)으로 기업·실소유자 심사, 보완 제출, 최소 상태 암호화와 만료·철회 처리를 구현했습니다. 계약 계정·심사 레벨 설정·실제 제공자 검증은 필요합니다. 위 샘플 접수는 전송되지 않으며 온체인 자격 증명은 발급하지 않습니다.

[미국·아부다비 구성요소 규칙 엔진](../docs/RULES.md)을 추가했습니다. 관할·고용/거래 형태·적용일에 따른 선택, 출처와 정수 계산 근거, 서명 검토를 지원합니다. 기본 규칙은 출처 확인 후보이며 전문 검토 승인은 포함하지 않습니다. 전체 세액·추가 관할·AI 초안·신고는 별도입니다.
